# Data provenance

`catalogue.snapshot.json` contains 7,898 named valid products from the complete Indonesia-market TSV export (8,290 source rows) retrieved on 16 October 2026. It retains incomplete labels with explicit null nutrients. `catalogue.manifest.json` records source URL, checksum and exclusions. This is the provider's country-filtered export, not a complete registry of all Indonesian-manufactured products.

`products.snapshot.json` contains 89 strict reference labels: 52 complete current export labels and 37 earlier source-attributed records retained without changing their original retrieval dates. Each record retains barcode, source link and conversion note. No missing nutrient is replaced with a fictional zero.

Open Food Facts is a collaborative database, not manufacturer verification. Its mirror can lag production; recipes, package sizes, units and contributions can contain errors. Verify the physical label before acting on a result. In particular, records can represent different package variants even when their names are similar.

**Prices in this snapshot are explicitly labelled simulation assumptions per serving. They are not verified Indonesian retailer prices or package prices.** The importer uses category-specific budget assumptions (Rp4,000 noodles, Rp10,000 cereal, Rp6,000 other categories). They make the budgeting algorithm inspectable, but do not satisfy a claim of accurate current retail pricing. Replace them with dated retailer evidence (`priceSource: RETAILER`, `priceSourceUrl`) or enter the price from your own purchase. Never relabel assumptions as verified data.

The five blueprint presets are separate `ILLUSTRATIVE_CASE` documents, not brand claims or catalogue evidence. Presets do not enter the empirical reference population or replacement candidate pool. The sodium 96th-percentile scenario in the brief is not hardcoded: the actual percentile is computed from the available category population and can differ.

`dictionary.snapshot.json` is generated in bulk from the [Open Food Facts additives taxonomy](https://static.openfoodfacts.org/data/taxonomies/additives.json) and [ingredients taxonomy](https://static.openfoodfacts.org/data/taxonomies/ingredients.json). The source datasets contain 764 and 6,654 nodes respectively. Each imported record retains provider ID, source URL, retrieval timestamp and normalized multilingual names. `dictionary.manifest.json` records raw-source SHA-256 checksums and counts. Duplicate canonical names are merged; local interpretation rules then merge exact aliases/codes while retaining provider provenance. No medical safety claim is copied automatically from a taxonomy risk flag.

Sugar descendants are selected by traversing provider sugar/glucose/fructose/honey branches with cycle protection. Additive function is mapped only where the provider supplies a compatible role; otherwise it remains UNKNOWN. The remaining 69 local rules add Indonesian interpretation, recognized sodium/GERD contexts and specific GI references, citing WHO, NIDDK, EFSA and University of Sydney. Generic E-number entries identify function, not a blanket safety claim. Unknown GI remains null. Pure sucrose (65, within a stated 60–65 range), glucose/dextrose (100), and fructose (19) references are not tested GI values for mixed products.

Refresh the country catalogue and eligible references with `npm run data:catalogue` (`data:import` is the older limited API importer) and the bulk glossary with `npm run data:dictionary`, then run `npm run db:seed`. Importers intentionally fail rather than invent records when a provider is unavailable. Checked-in snapshots keep Docker seeding functional offline after images/dependencies have been obtained.

`npm run data:prices` imports all IDR pages from the [Open Prices API](https://openfoodfacts.github.io/documentation/docs/Open-prices/prices/prices_list/). `prices.snapshot.json` contains 23 validated, proof-backed observations from 25 returned records. It omits contributor identities and rejects duplicate, future-dated, mismatched-barcode, non-IDR or unproven records. `prices.manifest.json` records retrieval time, raw-page SHA-256 hashes and exact catalogue coverage: one of 89 strict reference barcodes and 11 of 7,898 market catalogue products. These are dated community observations, not guaranteed current prices. The importer fails on incomplete pagination rather than publishing partial coverage.

Prices remain separate from the seeder's per-serving simulation values. `price_per: null` and product package quantity do not prove that a shelf price covers exactly one declared serving. No automatic serving conversion or replacement is performed. Inspect proof, package unit/count, serving count and date before promoting any observation to a dated retailer price. Refreshing observations therefore does not silently change shopping comparisons.

Provider datasheets preserve available descriptions, technological functions, Wikidata, CIQUAL, USDA FDC and EFSA evaluation links. BPOM/GSFA links are navigation aids, not an imported regulatory database. Full coverage and boundaries are recorded in `../DATA_COVERAGE.md`.
